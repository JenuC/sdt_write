# SPCM Python Wrapper

This is a Python wrapper for the Becker & Hickl SPCM DLL, which allows controlling and reading data from Single Photon Counting Modules (SPC).

## Requirements

- Windows OS
- Becker & Hickl SPCM software installed (including DLLs)
- Python 3.6 or higher
- NumPy
- Matplotlib (for plotting examples)

## Files

- `spcm_wrapper.py` - The main Python wrapper for the SPCM DLL
- `spcm_example.py` - Example script showing basic functionality of the SPCM wrapper
- `sdt_reader.py` - Utility for reading .sdt files generated by SPC modules
- `save_sdt_example.py` - Example showing how to save data to .sdt files

## Installation

1. Make sure you have the Becker & Hickl SPCM software installed on your system.
2. Place these Python files in your project directory.
3. Install the required Python dependencies:

```bash
pip install numpy matplotlib
```

## Using the SPCM Wrapper

### Basic Usage

```python
from spcm_wrapper import SPCM, SPC_Error

# Initialize the SPCM wrapper
spcm = SPCM()

# Initialize the module
result = spcm.init()
if result < 0:
    print(f"Error initializing SPC module: {spcm.get_error_string(result)}")
    exit(1)

# Get information about the first module (module 0)
mod_info, result = spcm.get_module_info(0)
if result == 0:
    print(f"Module Type: {mod_info.module_type}")
    print(f"Bus Number: {mod_info.bus_number}")
    print(f"Slot Number: {mod_info.slot_number}")

# Get the parameters for the first module
params, result = spcm.get_parameters(0)
if result == 0:
    print(f"Collection Time: {params.collect_time} s")
    print(f"TAC Range: {params.tac_range} ns")

# Close the library when done
spcm.close()
```

### Starting a Measurement

```python
from spcm_wrapper import SPCM

# Initialize the SPCM wrapper
spcm = SPCM()
spcm.init()

# Configure measurement parameters
mod_no = 0
params, _ = spcm.get_parameters(mod_no)
params.collect_time = 1.0  # 1 second collection time
params.stop_on_time = 1    # Stop on collection time
spcm.set_parameters(mod_no, params)

# Start the measurement
spcm.start_measurement(mod_no)

# Monitor the measurement progress
import time
while True:
    state, _ = spcm.test_state(mod_no)
    if state != 0:  # 0 = SPC_MEASURING
        print("Measurement completed")
        break
    time.sleep(0.1)

# Close the library when done
spcm.close()
```

### Saving Data to SDT Files

You can save measurement data to an .sdt file using the `save_data_to_sdtfile` method:

```python
from spcm_wrapper import SPCM
import numpy as np

# Initialize the SPCM wrapper
spcm = SPCM()
spcm.init()

# Method 1: Save data collected from a module
mod_no = 0
# ... (Perform a measurement)
data_buffer = ...  # Data buffer from SPC_read_data_block
result = spcm.save_data_to_sdtfile(mod_no, data_buffer, "measurement.sdt")
if result == 0:
    print("Data saved successfully")

# Method 2: Save synthetic or processed data
# Create some data (e.g., a simulated decay curve)
data_size = 4096  # 12-bit resolution
x = np.arange(data_size)
decay = 10000 * np.exp(-x / 500)  # Exponential decay with time constant 500
noise = np.random.poisson(decay + 1)
data = noise.astype(np.uint16)

# Save to .sdt file
result = spcm.save_data_to_sdtfile(0, data, "synthetic_decay.sdt")
if result == 0:
    print("Synthetic data saved successfully")

# Close the library when done
spcm.close()
```

For a more detailed example, see the `save_sdt_example.py` file.

## Reading SDT Files

You can use the `sdt_reader.py` utility to read .sdt files generated by SPC modules:

```python
from sdt_reader import SDTReader

# Create an SDT reader
reader = SDTReader()

# Show file information
info = reader.read_sdt_header("my_data.sdt")
if info:
    print(f"FIFO Type: {info.fifo_type}")
    print(f"Stream Type: {info.stream_type}")
    print(f"Total Photons: {info.read_photons + info.invalid_phot}")

# Plot decay curve
reader.plot_decay("my_data.sdt", channel=0, bin_width=1)

# Read individual photons
photons = reader.read_photons("my_data.sdt", max_photons=1000)
for photon in photons[:10]:
    print(photon)
```

You can also use the `sdt_reader.py` script directly from the command line:

```bash
python sdt_reader.py my_data.sdt -c 0 -b 1
python sdt_reader.py my_data.sdt -i  # Show file information only
```

## Troubleshooting

### DLL Not Found

If you get an error about the SPCM DLL not being found, make sure:

1. The Becker & Hickl SPCM software is installed
2. The DLL (spcm32.dll or spcm64.dll) is in one of the search paths
3. You're using the correct DLL version (32-bit or 64-bit) matching your Python installation

You can also specify the DLL path manually when creating the SPCM instance:

```python
spcm = SPCM(dll_path=r"C:\Path\To\Your\spcm64.dll")
```

### Error Codes

When a function returns a negative value, it indicates an error. You can get the error description using:

```python
error_message = spcm.get_error_string(error_code)
print(f"Error: {error_message}")
```
